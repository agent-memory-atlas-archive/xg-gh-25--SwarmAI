## 9. Lessons
- 一个 AttributeError 在 cmd_X(args) 里 `if args.NEW_FLAG:` 裸读, 而测试用 mock Namespace 调用 → 诊断根因前先问: 真实调用方 (argparse) 是否永远带该属性? 若 argparse 有 default → 真实路径永不触发, 根因是 TEST mock 没镜像真实接口, 不是代码缺 getattr. getattr 防御是 band-aid: 掩盖未来 mock drift + 削弱捕获畸形调用. 修 mock 一行 > 改 N 处生产代码.
- '统一加 getattr 保护'这类'一致性根修'论据要先数清真实基数: 我声称'同函数 ~20 处 getattr 兄弟', Gate-0 实测仅 5 处且守不同 attr — 4x 高估使'一致性'论据崩塌. 提'统一/一致'方案前先 grep 数真实分布 (P6: 别拿想象的基数支撑方案).
- 测试 mock 必须镜像的是'被测函数在该测试路径上实际裸读的接口子集', 不是'整个真实接口' — 过度 mirror (补所有 flag) 是 YAGNI; 精确 mirror (补该路径裸读的) + 注释说清边界 才对. force/reason 在 if args.status 块内, status=None 的测试不该为它们补 mock.
